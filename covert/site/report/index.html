When an agent finishes a trip, the last page of the passport carries a QR code back to headquarters. What they send is what fills this page.

REPORT FORMWHAT AGENTS SEND BACK

  • Which districts were completed
  • The place that left the strongest impression
  • How hard the assignments were
  • How easy it was to get around
  • Anything that should be changed
  • Photographs and a written report, if the agent wants to include them

HOW IT WORKS Filing a report is optional. Nothing in the kit depends on it, and no district needs it to count as finished. We read the reports to fix what didn't work and to plan the next operation.

ON PUBLISHING Nothing an agent sends is published here unless they've separately agreed to it. Reports used to improve the product stay internal. When this page does fill up, everything on it will be from a real agent who said yes.
